# 🎥 YouTube Clone

🌐 Live Demo
( https://youtube-clone-ai13.netlify.app/video/10/R2-yomhYAj4 )

A responsive YouTube clone built using **React** and **CSS**, leveraging the **YouTube Live API** to fetch real-time video data. This project replicates the core functionality of YouTube, including video listing, searching, and viewing—all powered by live API calls.

## 🚀 Features

- 📺 Watch videos with embedded players
- 🧭 Browse related and trending videos
- 💡 Responsive UI built with pure CSS
- ⚡ Live data fetching using YouTube Data API v3

## 🛠 Tech Stack

- **Frontend**: React
- **Styling**: CSS
- **Data**: YouTube Live API (Data API v3)


## 🧰 Getting Started

### 1. Clone the repository

git clone https://github.com/Aditya-Ingole/Youtube-Clone)

cd youtube-clone

npm install

REACT_APP_YOUTUBE_API_KEY=your_api_key_here

npm start
